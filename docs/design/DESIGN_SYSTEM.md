# Arcus Design System

## Brand

- **Name:** Arcus  
- **Voice:** Precise, calm, safety-first. No hype speeds.  
- **Logo concept:** Stylized nock notch forming an “A” over a thin trajectory arc.  
- **Palette:** Spruce `#1B3A2F`, moss `#2F6B4F`, brass `#C4A35A`, mist `#F3F1EA`, dark navy `#0B1520`.  
- **Type:** Material 3 system fonts initially; swap to a licensed geometric sans later if desired.  
- **Themes:** Light mist + dark navy. System default supported.

## Tokens

| Token | Value |
| --- | --- |
| Space | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| Radius | 12 controls, 16 cards |
| Touch | min 48×48 |
| Motion | 200–280ms ease-out page transitions |

## Components

- Calculator scaffold with sticky Calculate/Reset  
- Result card with formula, steps, assumptions, limitations, safety, citation  
- Catalog search + category sections  
- Setup Assistant multi-step wizard  

Intentionally different from the reference website’s look (no shared colors/fonts/layout).
