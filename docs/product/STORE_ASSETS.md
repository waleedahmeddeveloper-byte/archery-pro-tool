## Short description
Offline archery calculators for FOC, spine, speed, KE, momentum, and trajectory — with transparent formulas.

## Long description (draft)
Arcus helps compound, recurve, traditional, and crossbow archers plan arrow builds offline. Calculate FOC, arrow weight, grains per pound, kinetic energy, momentum, estimated speed, spine planning, and drop. The Setup Assistant carries one rig across tools. Every result shows the formula, working, assumptions, and safety notes. Optional sync pulls guide updates when you are online.
